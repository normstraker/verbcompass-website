# Current Priority — Educator Outreach Foundation

## Status

Implemented locally; deploy and private-review verification pending

This focused phase takes priority over general website polish while Founding
Tester recruitment is active. Its canonical implementation plan is maintained
in the Android repository at
`spanish-verb-companion/docs/EDUCATOR_OUTREACH_IMPLEMENTATION_PLAN.md`.

### Educator Resource

- Create `/educators/` as a value-first introduction to the free browser
  edition.
- Add practical educator workflows and a five-minute quick-start activity.
- State current product limits and privacy behavior clearly.
- Explain that free browser use does not require Android testing.

### Honest Product Direction

- Explain that the immediate goal is a public Spanish Android release through
  Google Play.
- Explain that Google Play Closed Testing is a required step toward Production
  access.
- Explain that completing the Spanish release establishes the foundation for
  future English-verb editions, beginning with English for Spanish-speaking
  learners.
- Keep the optional Founding Tester invitation separate from the primary free
  resource call to action.

### Feedback and Validation

- Add an educator feedback path that does not require a Google-account email.
- Update the Founding Tester form for teachers, tutors, and program leaders.
- Complete a small private educator review before broad outreach.
- Verify responsive behavior, accessibility, links, privacy coverage, and form
  handling.

# Long-Term Vision

The website should remain intentionally lightweight while serving as the public home for VerbCompass, the Spanish web edition, and the Android release.

The immediate priority is to make the web edition a useful public entry point and a natural path into the Founding Tester program. Installable VerbCompass applications will offer limited Free Access alongside Full Access across future language editions; the browser edition is outside that access model. The first public release will support English-speaking learners of Spanish. The next intended product direction is English verbs for Spanish-speaking learners; its design will be informed by lessons from web users and Android testers.
